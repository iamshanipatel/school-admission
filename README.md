# EAK International School - Admissions Landing Page (2027-28)

Frontend project built in **React.js + Vite + Tailwind CSS + Framer Motion** matching all assignment guidelines for EAK Pustak Pvt. Ltd.

## Features Included
1. **Hero Section** with clear CTA buttons ("Apply Now", "Schedule a Visit").
2. **Why Choose This School** with 6 key differentiators and hover micro-animations.
3. **Academic Programs** covering Primary, Middle, Secondary, and Senior Secondary.
4. **School Highlights** with statistics cards.
5. **Facilities Grid** showcasing smart infrastructure.
6. **Admission Process** 5-step numbered flow.
7. **Important Dates** timeline table.
8. **Required Documents** checklist.
9. **Fee Structure Preview** table.
10. **Parent Testimonials** carousel/grid cards.
11. **Frequently Asked Questions (FAQ)** with smooth collapsible accordion interaction.
12. **Final CTA & Interactive Enquiry Modal** with success confirmation state.
